# CardioPulse AI — Heart Disease Prediction System

A complete, production-grade Machine Learning system and visual analytics dashboard to predict the likelihood of ischemic heart disease from selected patient clinical biomarkers using the benchmark **UCI Heart Disease Dataset (Cleveland)**.

---

> [!WARNING]
> **CRITICAL MEDICAL DISCLAIMER**
> Predictions generated by this system are designed solely for **educational, data science research, and technical analytical evaluation**. They **DO NOT constitute a medical diagnosis, clinical triage, or treatment recommendation**. Real-world medical evaluations must always be conducted by certified physicians and cardiologists.

---

## 📌 Project Highlights & Core Features

- **Algorithms Evaluated:** 
  - **Logistic Regression** (L2 Regularized Ridge Classifier with Odds Ratio explainability)
  - **Support Vector Machine (SVM)** (RBF Kernel with Platt Probability Calibration via `CalibratedClassifierCV`)
  - **Random Forest Classifier** (150-Tree Bagged Ensemble with Mean Decrease Impurity feature ranking)
- **Dataset:** Official **UCI Cleveland Heart Disease Cohort** (303 clinical records, 13 physiological attributes, zero missing values after imputation).
- **Benchmark Performance:** Top test accuracy of **90.16%**, clinical sensitivity/recall of **92.86%**, and ROC-AUC of **0.9556**.
- **Special Features:**
  - **Live Multi-Model Comparison Studio:** Side-by-side metric cards, comparative bar charts, ROC curve overlays, interactive confusion matrix toggles, and feature importance rankings.
  - **Visual Analytics Suite:** Automated generation of correlation heatmaps, chest pain risk distributions, biological sex breakdown, and scatter clusters.
  - **Patient Risk Stratification Engine:** Tri-model consensus scorecards, interactive risk gauge, and personalized clinical risk vs. protective factors breakdown.
  - **Interactive Web Dashboard:** Modern dark-mode glassmorphic interface with one-click clinical presets and live parameter sliders.

## 📋 Medical Features Glossary

The system analyzes 13 diagnostic parameters collected during cardiac evaluation:

1. **`age`**: Age in years (29 to 77).
2. **`sex`**: Biological sex (1 = Male, 0 = Female).
3. **`cp`**: Chest pain type:
   - `0`: Typical angina (substernal exertional pain).
   - `1`: Atypical angina.
   - `2`: Non-anginal discomfort.
   - `3`: Asymptomatic (silent ischemia).
4. **`trestbps`**: Resting blood pressure on hospital admission (mm Hg; hypertension marked at ≥ 140 mm Hg).
5. **`chol`**: Serum cholesterol in mg/dl (hypercholesterolemia marked at ≥ 240 mg/dl).
6. **`fbs`**: Fasting blood sugar > 120 mg/dl (1 = Diabetic/elevated; 0 = Normal).
7. **`restecg`**: Resting electrocardiographic findings:
   - `0`: Normal.
   - `1`: ST-T wave abnormality (T wave inversions or ST deviation > 0.05 mV).
   - `2`: Left ventricular hypertrophy by Estes' criteria.
8. **`thalach`**: Maximum heart rate achieved during exercise stress test (bpm). Higher rate indicates healthy cardiac reserve.
9. **`exang`**: Exercise-induced angina (1 = Yes, 0 = No).
10. **`oldpeak`**: ST-segment depression induced by exercise relative to rest (mm; values > 1.0 mm indicate ischemia).
11. **`slope`**: Slope of the peak exercise ST segment:
    - `0`: Upsloping (normal response).
    - `1`: Flat (moderate ischemic risk).
    - `2`: Downsloping (severe ischemia).
12. **`ca`**: Number of major coronary vessels (0–3) colored by fluoroscopy (stenosis indicator).
13. **`thal`**: Thallium scintigraphy perfusion defect:
    - `1`: Normal blood flow.
    - `2`: Fixed defect (non-viable tissue / prior infarction).
    - `3`: Reversible defect (viable but ischemic tissue).

## 🚀 Getting Started

### 1. Prerequisites & Environment Setup

Ensure Python 3.10+ is installed:

```bash
# Clone or navigate to the workspace
cd "ml project"

# Create a virtual environment
python3 -m venv venv

# Activate virtual environment
source venv/bin/activate  # On Linux/macOS
# venv\Scripts\activate   # On Windows

# Install dependencies
pip install -r requirements.txt
```

### 2. Retrain Machine Learning Models

To re-run data ingestion, 5-fold cross-validation, and regenerate all publication figures:

```bash
python train.py
```

### 3. Launch the Interactive Web Dashboard

```bash
python app.py
```

Open your browser and navigate to:
```
http://127.0.0.1:5050
```

## 🌐 REST API Endpoints

The Flask server exposes RESTful JSON endpoints for client applications or automated testing:

### 1. Predict Cardiac Risk
- **Endpoint:** `POST /api/predict`
- **Request Body (JSON):**
  ```json
  {
    "age": 60,
    "sex": 1,
    "cp": 3,
    "trestbps": 150,
    "chol": 270,
    "fbs": 0,
    "restecg": 1,
    "thalach": 120,
    "exang": 1,
    "oldpeak": 2.0,
    "slope": 1,
    "ca": 2,
    "thal": 3
  }
  ```
- **Response (JSON):**
  ```json
  {
    "ensemble": {
      "prediction": 1,
      "prediction_label": "Heart Disease Detected",
      "probability": 0.9909,
      "risk_percentage": 99.1,
      "risk_tier": "High Risk",
      "clinical_advice": "Significant cardiac risk indicators present..."
    },
    "models": {
      "Logistic Regression": { "prediction": 1, "probability": 0.9945 },
      "SVM": { "prediction": 1, "probability": 0.9864 },
      "Random Forest": { "prediction": 1, "probability": 0.9906 }
    },
    "risk_factors": [...],
    "protective_factors": [...]
  }
  ```

### 2. Fetch Comparative Metrics & Analytics
- **Endpoint:** `GET /api/metrics`
- **Returns:** Test scores, cross-validation summaries, ROC curve points, and feature importances.

### 3. Retrieve Preset Patient Profiles
- **Endpoint:** `GET /api/sample-patients`
- **Returns:** Pre-configured profiles (`low_risk`, `moderate_risk`, `high_risk`) and a randomized patient from the UCI cohort with ground truth diagnosis.

## 📈 Why Choose This Project?

1. **High Real-World Societal Relevance:** Cardiovascular disease is the leading global cause of mortality. Automated screening systems assist clinical decision support by highlighting high-risk patients who require urgent diagnostic triage.
2. **Algorithmic Diversity:** Combines an interpretable linear model (**Logistic Regression**), a maximum-margin kernel classifier (**SVM**), and a nonlinear tree ensemble (**Random Forest**).
3. **Rigorous Clinical Ground Truth:** Meticulously parsed from the authentic UCI Cleveland repository, verifying that features like ST depression and fluoroscopy stenosis correlate with coronary artery disease according to clinical cardiological standards.
4. **Responsible AI Practices:** Embedded medical disclaimers, Platt probability calibration, and multi-factor explanation tags guard against over-reliance on automated classifications.
